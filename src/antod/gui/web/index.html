DPI-Evasion & Obfuscated Network Traffic Detection

Modern malware hides how it communicates through packet padding, timing jitter, and protocol mimicry. ANTOD learns bidirectional packet shape and aggregate moments to detect obfuscated traffic where signature-based DPI fails, stress-tested under domain-constrained adversarial machine learning.

CLASS 0

Benign

Legitimate application flows (web, video, VoIP, bulk transfers, TLS)

CLASS 1

Malicious Plain

Undisguised attacks (C2 beacons, scans, plain exfiltration)

CLASS 2

Malicious Obfuscated

Reshaped attacks using padding, jitter & tunneling to evade DPI

Core Architectural Insights

Key Findings
  • Hybrid CNN+MLP dominates: Combining a 1D-CNN (packet sequence) and an MLP (51 aggregate features) reaches 96.88% Accuracy and 94.24% Obfuscated Recall.
  • Plain attacks are trivial: Undisguised malicious traffic is caught with >99.6% recall; obfuscation is where all real detection challenge lies.
  • Feature engineering matters: Size-grid occupancy (fingerprint of block padding) and timing regularity features let a Random Forest match the deep models on clean data.
  • Realistic base-rate precision: Re-weighting to a realistic 99% benign network yields 74.7% precision with only 32.7 false alerts per 10k flows.
