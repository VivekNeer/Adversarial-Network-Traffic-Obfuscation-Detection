Benign Traffic CLASS 0
Unmodified or tunnelled legitimate traffic (web, adaptive video, VoIP, file transfer). Tunnelled/VPN benign traffic is modelled to prevent false flagging.
Malicious Plain CLASS 1
Undisguised hostile traffic (periodic C2 beacons, brute-force probes, direct exfiltration). Easily caught by statistical moments (>99.6% recall).
Malicious Obfuscated CLASS 2
Attacks modified via block/random padding, timing jitter, packet fragmentation, and encapsulation to intentionally evade signature-based DPI engines.
Empirical Research Findings Evaluation Summary

• Dual-View Hybrid Dominance: Combining packet sequence convolutions with 51 statistical aggregates yields 96.88% Accuracy and 94.24% Obfuscated Recall, outperforming single-view baselines.

• Obfuscation-Specific Features: Size-grid occupancy (detecting 64/128-byte block boundaries) and timing coefficient-of-variation carry robust evasion signals that survive encryption.

• Operational Reliability: Temperature scaling calibration (T = 0.73) reduces Expected Calibration Error to 0.0062, guaranteeing predictable risk scores for production deployment.
